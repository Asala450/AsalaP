# Дәрігерге жазылу жүйесі (Doctor Appointment System)

## Жоба туралы

Бұл веб-қосымша пайдаланушыларға дәрігерлер туралы ақпаратты көруге, мамандық бойынша дәрігерді таңдауға және қабылдауға онлайн жазылуға мүмкіндік береді. Жоба PHP, MySQL және заманауи веб-технологиялар көмегімен әзірленеді.

## Негізгі мүмкіндіктер

- Пациенттерді тіркеу және жүйеге кіру (Authentication)
- Дәрігерлер тізімін қарау
- Мамандығы бойынша дәрігерлерді іздеу және сүзу
- Қабылдауға жазылу (Appointment Booking)
- Қабылдау күні мен уақытын таңдау
- Жазылған қабылдауларды қарау және басқару
- Жеке кабинет және пациент мәліметтерін өңдеу
- Әкімші арқылы дәрігерлер мен қабылдауларды басқару
- Деректерді тексеру және қауіпсіз сақтау

## Дерекқор құрылымы (Кестелер)

- **users**: Пайдаланушылар мәліметтері (id, name, email, phone, password, role)
- **doctors**: Дәрігерлер туралы ақпарат (id, name, specialty, description, phone)
- **appointments**: Қабылдау туралы мәліметтер (id, user_id, doctor_id, appointment_date, appointment_time, status)
- **specialties**: Дәрігер мамандықтары (id, name)

## Негізгі беттер тізімі

1. `index.php` — Басты бет
2. `doctors.php` — Дәрігерлер тізімі
3. `doctor_detail.php` — Дәрігер туралы толық ақпарат
4. `register.php` — Пациентті тіркеу
5. `login.php` — Жүйеге кіру
6. `appointment.php` — Қабылдауға жазылу
7. `my_appointments.php` — Менің қабылдауларым
8. `profile.php` — Жеке кабинет
9. `admin.php` — Әкімші панелі

## Технологиялар

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development tools:** Visual Studio Code, Git, GitHub, XAMPP

## Жобаның мақсаты

Пациенттерге медициналық қызметтерді пайдалануды жеңілдету, дәрігерге жазылу процесін автоматтандыру және қабылдаулар туралы ақпаратты бір жүйеде сақтау.

## Жобаны іске қосу

1. XAMPP бағдарламасын орнату.
2. Жоба қалтасын `htdocs` бумасына орналастыру.
3. Apache және MySQL қызметтерін іске қосу.
4. phpMyAdmin арқылы дерекқор құру.
5. PHP файлдарында дерекқорға қосылу параметрлерін баптау.
6. Браузерде `http://localhost/doctor-appointment-system/` мекенжайын ашу.
